# Projeto 03 – Peça jurídica a partir do relato de um caso

Atividade: Oficina prática (IA Jurídica – Unidade 02, Aula 06). Trabalho individual.

**Objetivo:** organizar relato bruto em fatos e pedidos, localizar o fundamento legal **apenas** nos documentos de apoio e gerar uma minuta pronta para revisão.

**Estrutura:** `apoio/` (relato, notas fiscais, legislação) · `docs/protocolo.md` · `docs/registro.md` · `saida/minutas/`

**Responsável pela revisão:** advogado responsável, antes de assinar ou protocolar.
