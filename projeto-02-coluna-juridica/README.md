# Projeto 02 – Coluna semanal de um advogado em revista especializada

Atividade: Oficina prática (IA Jurídica – Unidade 02, Aula 06). Trabalho individual.

**Objetivo:** o advogado entra só com ideia, narrativa e objetivo; a IA organiza o roteiro, aplica o guia de estilo e entrega rascunho completo dentro do limite de caracteres.

**Estrutura:** `apoio/` (guia de estilo e colunas anteriores fictícias) · `docs/protocolo.md` · `docs/registro.md` · `saida/rascunhos/`

**Responsável pela revisão:** o próprio advogado, autor da coluna, antes de qualquer envio à redação.
